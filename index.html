Goal of this Project

    I started this project with the goal of finding "incorrectly" priced Option Contracts. Option sellers generally target expensive options which generally means options with a high annual return relative to the probability that the contract will expire worthless. For example, if a put option is offering 30% annualized returns with 75% chance the contract expires worthless.

Takeaway

    After spending hours looking at countless daily CSV files from Barchart visualized with this plot, I realized there is no such thing as an incorrectly priced option contract. Any outliers on the plot can be explained by either high IV or low Moneyness (terms explained in Jupyter Notebook), and the remaining few are dying companies like intel ;).
    Although I didn't find a free money cheat code ;), This project taught me a lot of things about options trading that I should've learned a long time ago. This is the first time I have ever created something with code that has become integral to my daily life and it feels great. At market open each day I sit down at my desk with a coffee and pull up my scatter plot to view the daily csv file. Now that I have this project on a github page, I am tempted to share it with r/thetagang (subreddit for options sellers) and see what some more experienced traders think of my chosen axes.
